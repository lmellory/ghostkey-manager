- [ ] Секреты только через `wrangler secret put`; `.env` не в git.

- [ ] `npm test` проходит.

- [ ] Восстановление из бэкапа проверено на тестовой БД (docs/BACKUP.md).

## Ручные тесты
1. **Регистрация по инвайту:** новый аккаунт без кода получает только запрос кода; с верным кодом — доступ.
2. **Повторное использование инвайта:** тот же код со второго аккаунта → «недействителен».
3. **Чужие записи:** с аккаунта B запросите `/api/entries/<id записи A>` (PUT/DELETE) → 404; список B не содержит записей A.
4. **Поддельный initData / устаревший (>1 ч):** запрос → 401.
5. **Webhook без секретного заголовка:** `curl -X POST <url>/webhook` → 403.
6. **Неверный мастер-пароль:** 5 попыток → блокировка с растущей задержкой до 15 мин; верный пароль после ожидания работает.
7. **Автоблокировка:** 5 мин бездействия и 60 с в фоне → экран разблокировки.
8. **Пароль в чат:** отправьте боту текст как пользователь → сообщение удалено, предупреждение.
9. **Дубликат названия:** «Заменить» / «(2)» / «Отмена».
10. **Экспорт/импорт:** экспорт → удалить запись → импорт возвращает её.
11. **Rate limit:** 130 запросов/мин с одного IP → 429.
12. **Потеря мастер-пароля:** подтвердите, что восстановление невозможно (ожидаемое поведение).
13. **/revoke:** записи пользователя удалены, доступ закрыт.

## Известные ограничения
- **Доверие к деплою.** Код Mini App раздаёт ваш Worker: тот, кто контролирует деплой, может подменить JS и украсть мастер-пароли. Защита — только 2FA и дисциплина.
- **PBKDF2, не Argon2id:** слабее против GPU-перебора. Мастер-пароль — длинная фраза.
- **Auth-токен (вариант А2)** — производная от мастер-пароля величина уходит на сервер (хранится хеш). Ключ шифрования с неё не восстановить, но это отступление от буквы ТЗ.
- **Метаданные видны:** число записей, даты, приблизительные размеры (округлены до 256 байт).
- **Буфер обмена:** очистка через 30 с — best-effort, в WebView может не сработать. Экспорт из буфера не стирается автоматически.
- **Экспорт — текст в буфере**, не файл: скачивание Blob в Mini App в Telegram ненадёжно. Файл работает только для того же аккаунта и мастер-пароля.
- **Пароль в чате:** бот удаляет сообщение, но оно уже побывало на серверах Telegram.
- **Rate limiting** на D1 — грубый (окно 1 мин); IP берётся из заголовка Cloudflare.
- **Смена мастер-пароля** не реализована (потребует перешифрования всех записей).
- **Не проверено мной в реальной среде:** деплой на Cloudflare, лимиты бесплатного тарифа, работа Drive-загрузки, поведение `showPopup`/`BackButton` в разных клиентах Telegram.
